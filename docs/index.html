核心功能

全链路 AI 开发支持

从需求到部署，每个环节都有 AI 智能辅助，让开发更高效、更规范

📋

智能需求分析

自动解析用户需求，生成结构化 PRD 文档，提取关键业务实体和流程

工作流程

6 阶段标准化流程

遵循软件工程方法论，每个阶段都有明确的输入输出和检查点

0

项目初始化

创建 HAFW 工作空间，初始化项目上下文和目录结构

/hafw-context-init {项目名称}
1

需求分析

分析需求、生成 PRD、评审并拆解为可执行任务

/hafw-req-analysis → /hafw-req-spec → /hafw-req-breakdown
2

系统设计

架构设计、数据库设计、API 设计并行进行

/hafw-design-arch → /hafw-design-db + /hafw-design-api
3

代码开发

生成代码、生成测试、代码审查循环迭代

/hafw-dev-code → /hafw-dev-test → /hafw-dev-review
4

质量保障

代码扫描、自动化测试、生成质量报告

/hafw-qa-scan → /hafw-qa-test → /hafw-qa-report
5

部署运维

构建打包、发布部署、配置监控告警

/hafw-deploy-build → /hafw-deploy-release → /hafw-deploy-monitor
