# HAFW 上下文导入指令

## 目标

导入 HAFW 项目上下文，用于恢复备份或迁移项目。

## 用法

```bash
# 导入上下文文件
/hafw-context-import {文件路径}

# 导入并指定新名称
/hafw-context-import {文件路径} --project={新项目名称}

# 强制覆盖现有项目
/hafw-context-import {文件路径} --force
```

## 参数说明

| 参数 | 说明 | 默认值 |
|-----|------|--------|
| 文件路径 | 要导入的文件路径 | 必填 |
| --project | 新项目名称 | 使用原项目名称 |
| --force | 强制覆盖 | false |
| --validate | 验证导入文件 | true |

## 导入后操作

导入完成后自动执行：
1. 验证数据完整性
2. 重建文档索引
3. 恢复任务状态
4. 更新项目列表
5. 记录导入日志

## 从 JSON 导入

```bash
/hafw-context-import /backup/project-context.json --format=json
```

JSON 格式要求：
```json
{
  "import_format": "hafw-context-v1",
  "project": {
    "id": "{项目ID}",
    "name": "{项目名称}",
    "version": "{版本}"
  },
  "context": {
    "requirements": {...},
    "design": {...},
    "development": {...},
    "quality": {...},
    "deployment": {...}
  },
  "tasks": {...},
  "timeline": {...}
}
```

## 批量导入

```bash
# 导入多个项目
/hafw-context-import /exports/*.zip --batch

# 从目录导入
/hafw-context-import /backup/hafw-projects/ --directory
```
