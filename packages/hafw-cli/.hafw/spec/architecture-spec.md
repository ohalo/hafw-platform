## 5. 接口架构

### 5.1 API 设计规范

#### 5.1.1 RESTful API 规范
- URL 规范: `/api/v{版本}/{资源}`
- HTTP 方法: GET(查询)、POST(创建)、PUT(更新)、DELETE(删除)
- 状态码: 200(成功)、400(请求错误)、401(未认证)、403(无权限)、500(服务器错误)

#### 5.1.2 请求/响应格式
```json
// 请求示例
{
  "param1": "value1",
  "param2": "value2"
}

// 响应示例
{
  "code": 200,
  "message": "success",
  "data": {
    "key": "value"
  }
}
```
