# HAFW 时间线查看指令

## 目标

查看 HAFW 项目的完整时间线，追踪所有活动和变更历史。

## 用法

```bash
# 查看当前项目时间线
/hafw-context-timeline

# 查看指定项目时间线
/hafw-context-timeline --project={项目名称}

# 查看最近 N 天的活动
/hafw-context-timeline --days=7

# 查看特定类型事件
/hafw-context-timeline --type=task
```

## 参数说明

| 参数 | 说明 | 可选值 |
|-----|------|--------|
| --project | 项目名称 | 已初始化项目 |
| --days | 最近天数 | 1-365 |
| --type | 事件类型 | all/init/requirement/design/dev/quality/deploy/task |

## 事件类型说明

| 图标 | 类型 | 说明 |
|-----|------|------|
| 🚀 | project_initialized | 项目初始化 |
| 🔍 | requirement_analysis | 需求分析 |
| 📝 | requirement_spec | 需求规范 |
| ✅ | requirement_review | 需求评审 |
| 🎨 | design_architecture | 架构设计 |
| 🗄️ | design_database | 数据库设计 |
| 🔌 | design_api | API设计 |
| 💻 | dev_code | 代码开发 |
| 🧪 | dev_test | 测试开发 |
| 👀 | dev_review | 代码审查 |
| 🔍 | qa_scan | 质量扫描 |
| ✅ | qa_test | 质量测试 |
| 📊 | qa_report | 质量报告 |
| 📦 | deploy_build | 构建打包 |
| 🚀 | deploy_release | 发布部署 |
| 📈 | deploy_monitor | 监控运维 |
| ➕ | task_created | 任务创建 |
| 📝 | task_updated | 任务更新 |
| ✅ | task_completed | 任务完成 |
| ⏸️ | task_paused | 任务暂停 |

## 导出时间线

```bash
# 导出为 Markdown
/hafw-context-timeline --export=md --output=timeline.md

# 导出为 JSON
/hafw-context-timeline --export=json --output=timeline.json

# 导出为 PDF
/hafw-context-timeline --export=pdf --output=timeline.pdf
```

## 过滤和搜索

```bash
# 查看特定操作人的活动
/hafw-context-timeline --operator=张三

# 查看特定任务的活动
/hafw-context-timeline --task=T001-001

# 查看特定需求的活动
/hafw-context-timeline --requirement=REQ-001

# 搜索关键词
/hafw-context-timeline --search="数据库"
```
