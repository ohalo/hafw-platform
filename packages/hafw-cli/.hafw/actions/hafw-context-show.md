# HAFW 上下文查看指令

## 目标

查看当前 HAFW 项目的上下文状态，包括项目信息、阶段进度、任务状态等。

## 用法

```bash
# 查看当前项目完整上下文
/hafw-context-show

# 查看指定项目上下文
/hafw-context-show --project={项目名称}

# 查看指定阶段上下文
/hafw-context-show --phase=requirements

# 查看详细信息
/hafw-context-show --detail
```

## 参数说明

| 参数 | 说明 | 可选值 |
|-----|------|--------|
| --project | 指定项目名称 | 已初始化项目 |
| --phase | 指定阶段 | requirements/design/development/quality/development |
| --detail | 显示详细信息 | - |
