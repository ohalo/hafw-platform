# HAFW 上下文切换指令

## 目标

切换当前活动的 HAFW 项目上下文，或查看所有可用项目列表。

## 用法

```bash
# 切换到指定项目
/hafw-context-switch {项目名称}

# 列出所有项目
/hafw-context-switch --list

# 切换到上一个项目
/hafw-context-switch -
```

## 参数说明

| 参数 | 说明 |
|-----|------|
| 项目名称 | 要切换到的项目名称 |
| --list | 列出所有可用项目 |
| - | 切换到上一个项目 |

## 上下文切换机制

### 1. 保存当前上下文
```json
{
  "action": "save_context",
  "project": "用户积分系统",
  "timestamp": "2024-03-13T15:35:00Z",
  "context": {
    "current_requirement": "REQ-001",
    "current_design": "ARCH-001",
    "current_task": "T001-003",
    "workspace_state": "saved"
  }
}
```

### 2. 加载目标上下文
```json
{
  "action": "load_context",
  "project": "订单管理系统",
  "timestamp": "2024-03-13T15:35:01Z",
  "context": {
    "current_requirement": "REQ-002",
    "current_design": "ARCH-002",
    "current_task": null,
    "workspace_state": "loaded"
  }
}
```

### 3. 更新全局配置
```json
{
  "active_project": "订单管理系统",
  "project_history": [
    "用户积分系统",
    "订单管理系统"
  ],
  "last_switch": "2024-03-13T15:35:01Z"
}
```

## 快捷切换

```bash
# 切换到最近使用的项目
/hafw-context-switch -

# 切换到第 N 个项目
/hafw-context-switch --index=2
```

## 注意事项

1. **自动保存**: 切换前自动保存当前项目上下文
2. **状态恢复**: 切换后恢复项目的完整工作状态
3. **历史记录**: 保存最近 10 个项目切换历史
4. **并发安全**: 同一时间只能有一个活动项目
