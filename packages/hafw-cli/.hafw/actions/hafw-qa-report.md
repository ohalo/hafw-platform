# HAFW 质量报告指令

## 目标

汇总各项质量指标，生成综合质量报告，为项目决策提供数据支持。

## 输入

- 代码扫描结果
- 测试报告
- 代码审查结果
- 生产环境监控数据

## 执行步骤

### 1. 收集质量数据

收集各阶段质量数据：
- 代码规范检查结果
- 测试覆盖率数据
- 缺陷统计数据
- 性能指标数据
- 安全扫描结果

### 2. 计算质量指标

| 指标 | 计算公式 | 目标值 |
|-----|---------|--------|
| 代码规范合规率 | 合规文件数 / 总文件数 | > 95% |
| 测试覆盖率 | 覆盖代码行 / 总代码行 | > 80% |
| 缺陷密度 | 缺陷数 / 千行代码 | < 0.5 |
| 严重缺陷率 | 严重缺陷数 / 总缺陷数 | < 10% |
| 技术债务率 | 债务时间 / 开发时间 | < 10% |

### 3. 生成质量报告

```markdown

|-----|------|
| 报告周期 | {start} ~ {end} |

| 生成日期 | {date} |
```
