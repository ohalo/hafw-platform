# HAFW 任务列表查询指令

## 目标

查看任务列表、进度统计和个人待办。

## 用法

```bash
# 查看需求的所有任务
/hafw-task-list {需求ID}

# 查看我的任务
/hafw-task-list --owner={username}

# 查看特定状态的任务
/hafw-task-list {需求ID} --status=开发中

# 查看今日任务
/hafw-task-list --today

# 查看我今日的任务
/hafw-task-list --owner={username} --today
```

## 筛选选项

| 选项 | 说明 | 示例 |
|-----|------|------|
| --owner | 按负责人筛选 | --owner=zhangsan |
| --status | 按状态筛选 | --status=开发中 |
| --priority | 按优先级筛选 | --priority=P0 |
| --today | 今日任务 | --today |
| --week | 本周任务 | --week |
| --overdue | 逾期任务 | --overdue |

## 导出功能

```bash
# 导出为 Excel
/hafw-task-list REQ-001 --export=excel

# 导出为 Markdown
/hafw-task-list REQ-001 --export=md
```
